U16b · Forgot PIN — Recovery Flow

Companion to U16. The PIN is stored on-device only, so recovery delegates to something the device already trusts. Three paths by friction: Biometrics (frictionless, nothing erased) → Device Passcode (OS handoff) → Erase & Reset (last resort, private shelf wiped with explicit warning). Built from the same PinOverlay primitives as U16.
