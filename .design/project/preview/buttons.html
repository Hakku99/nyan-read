Three heights, no others
Every Nyan button MUST be exactly one of 36 · 44 · 56 px tall. Set height, never min-height + padding-y — the latter lets icons or two-line labels balloon the box.
36 px
SECONDARY · in-card CTAs, compact action sheets (e.g. continue-reading hero, sort-by row)
44 px
DEFAULT · the only height for body-flow CTAs · matches minTapTarget
52 px
HERO · sticky bottom CTA only (e.g. paywall, full-screen import). Avoid elsewhere.
56 px
FAB · floating action only — Bookshelf import. Never label this; it stays a circle-square icon.

Rules
  • height, not min-height + padding-y. Pick 36 · 44 · 52 · 56 and stick to it.
  • padding is horizontal only — 14 · 24 · 28 for sm · md · lg.
  • white-space: nowrap + text-overflow: ellipsis on the label span. Buttons never wrap to two lines.
  • Icon size always one step below font-size: 18 px icon next to 16 px label, 16 px icon next to 14 px label.
  • Sticky bottom CTA = 52 px. Body CTA = 44 px. In-card CTA = 36 px. Floating action = 56 px square. Anything else is wrong.
  • Never put two body CTAs at 52 px on the same screen — the eye loses the primary.
