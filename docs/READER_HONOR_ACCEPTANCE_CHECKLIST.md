# HONOR 真机验收清单（PR #10 合并前）

适用设备：HONOR BKQ-N49（60 Hz，Android）。被测版本：PR #10 当前 head。
iOS 无设备，不在本清单内，PR 描述中标为"未验证"。

## 0. 准备

- 安装被测版本的 release APK，建议用独立包名（如 `com.example.nyan_read.releasehonor`），
  避免覆盖日常使用的数据。构建与安装由 Claude 协助，需要连接手机并打开 USB 调试；
  只用于 `adb install` 和读取日志，不读取书籍内容。
- 测试样本（放进手机书库，勿用私人书籍）：
  - TXT：含一段超长段落的文本。
  - EPUB：含插图的书；另备章节最大的一本（用于 B2）。
  - PDF：扫描版一本、图文混排一本、**页数多于 10 页**的长 PDF 一本（例如 100 页以上）。
- 设置页 → "翻页模式"只有两个选项："左右翻页"（对应代码里的 `PageTurnMode.tap`，走翻页快照管线）和"上下翻页"（`PageTurnMode.swipe`，垂直滚动）。第 2 节必须选"左右翻页"；其余项两种模式各过一遍更好。
- 开始前关闭其他悬浮窗（负一屏、侧边栏等），避免遮挡影响观察。

## 门槛说明

- **门槛**：合并前必须通过。
- **补验**：建议合并前完成，来不及可合并后补，PR 描述需写明。

## 1. 位置恢复（门槛）

对 TXT、EPUB 插图、扫描 PDF、图文混排 PDF **各做一遍**：

| 步骤 | 预期 |
| --- | --- |
| 1. 打开书，向后翻 3 页，再向前翻 1 页，记下页内第一行文字（PDF 记页码） | 翻页流畅，无空白页、无闪回上一页 |
| 2. 按 Home 回桌面，等待约 10 秒，再回到应用 | 仍在同一位置 |
| 3. 在多任务里划掉应用，重新打开，进入同一本书 | 回到记下的位置；EPUB 回到同一张插图；PDF 页码和画面一致 |

结果：TXT ☐　EPUB ☐　扫描 PDF ☐　混排 PDF ☐　异常说明：______

## 3. PDF 目录显示为中文（门槛）

| 步骤 | 预期 |
| --- | --- |
| 1. 语言设为中文，打开长 PDF，点底栏"目录" | 目录条目显示"第 1 页""第 11 页"……，**没有** `Page 1` |
| 2. 点"第 11 页" | 跳到第 11 页 |
| 3. 语言切为英文，重开目录 | 显示 `Page 1`、`Page 11` |
| 4. 查看阅读器顶部或进度处的章节摘要 | 与目录同语言 |

结果：中文 ☐　英文 ☐　跳页 ☐

## 4. 中文 PIN 界面（门槛）

语言设为中文，用测试 PIN：

| 步骤 | 预期 |
| --- | --- |
| 1. 设置 PIN，再进入私密书架 | 界面文案全中文，无排版错位、无截断 |
| 2. 故意输错 1 次 | 显示普通错误反馈，不出现锁定 |
| 3. 连续输错到第 5 次 | 出现锁定提示和约 30 秒倒计时，数字键停用 |
| 4. 倒计时期间划掉应用重开，进入私密书架 | 倒计时接着走，而不是重新开始 |
| 5. 倒计时结束后输入正确 PIN | 解锁成功 |
