# 第 08 项：横向翻页准备与取消

日期：2026-10-23。基于 `3878caf`（第 05 项），在
`codex/reader-turn-location-fixes` 上独立整理；第 13 项绘制优化不包含在本提交中。

## 修复范围

- 旧页截图遮住实际正文，导航只派发一次；目标页布局和可见图片就绪后，才开始原有的 360ms 横向动画。取消动画中途切换内容的旧时序。
- `PageTurnRequest` 贯穿截图、导航队列、目标图像等待和 UI 超时。未开始的导航可取消；已接受的导航保留引擎真实位置，取消呈现不回滚位置、不重复派发。
- 截图限时 350ms，导航和就绪等待各限时 1500ms，并受 UI 整体 3 秒保护。截图不可用时直接翻页一次；目标图像未就绪时显示原阅读器的加载状态。
- 一个容器最多保留一个未返回的 GPU 截图任务；迟到图像释放，不能触发迟到导航。正常结束、取消和销毁释放截图与图片监听。
- 模式、排版、颜色、视口变化，以及打开浮层、进入后台和退出，取消旧呈现。正文保持挂载。
- Controller 队列错误传回当前调用方，同时允许后续请求继续；UI 使用现有本地化错误反馈。
- 补齐正文对模式、字号、行距、字体及颜色的最小订阅，避免引擎已切换模式、翻页容器仍使用旧配置。

## 契约与回滚

新增可选 `PagePresentationCapability.waitForPagePresentation(PageTurnRequest)`；
`ReaderController.nextPage/previousPage` 增加可选请求参数，并提供真实位置和呈现就绪代理。
既有调用兼容。`ReaderEngine` 导航签名、`ReadingPosition` JSON、章节定位、SQLite schema 不变。
PDF 使用公共 `PdfPageImageProvider`，EPUB 复用现有图片解码；没有第二份位置或图片缓存。

回滚应成组撤销本提交的请求、Controller/UI 调度和图像就绪能力，不需要数据迁移。
保留第 05 项的正文稳定挂载与位置字段。
