# docs

Paths under `.dart_tool/` in these documents are **local evidence** from the
author's machine. That directory is git-ignored, so those paths do not resolve
in a clone. The conclusions are recorded in the documents; large raw records
are condensed in `baselines/`.

## Index

- `PERFORMANCE.md` — performance rules and verification checklist.
- `READER_HISTORY.md` — history of the reader turn / position fixes and the experimental item 13.
- `READER_HONOR_ACCEPTANCE_CHECKLIST.md` — device acceptance steps for PR 10.
- `DESIGN_LIBRARY_FOLDERS.md` — library-folder design notes.
- `BACKLOG.md` — open items.

New investigation or acceptance notes belong in the pull request description, not in a new file here.
