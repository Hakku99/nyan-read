# Baseline evidence

Files here are **condensed** copies of the original measurement records. Each
has a `_summary` block with the SHA-256 and size of the full file; the full
files are local evidence and are not stored in git. Large per-round arrays and
hash manifests are replaced by `<N items omitted>` markers.

`tool/reader_baseline/package_13a.py` still writes the full 13A record to
`reader_performance_13a_2026-11-04.json`; condense it again before committing.
